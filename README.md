# MedyaHub — Premium Sosyal Medya Yönetim Paneli Prototipi

Sade, modern ve premium hissettiren çalışan prototip.

## Özellikler
- Şık giriş ekranı
- Temiz dashboard + grafikler
- İçerik takvimi
- Gönderi oluşturma & zamanlama (localStorage)
- Analitik
- Inbox
- Hesaplar

## Çalıştırma
`index.html` dosyasını tarayıcıda açın veya:
```bash
npx serve .
```

Demo giriş: herhangi bir bilgiyle giriş yapabilirsiniz.
