# MedyaHub — Dark Mode Destekli Sosyal Medya Yönetim Paneli

Sade, modern ve premium hissettiren çalışan prototip. Teal/Cyan renk paleti + tam dark mode.

## Özellikler
- Dark / Light mode geçişi (tercih kaydedilir)
- Temiz dashboard + grafikler
- İçerik takvimi
- Gönderi oluşturma & zamanlama
- Analitik, Inbox, Hesaplar
- Sandbox ortamlarında bile çalışan güvenli depolama

## Çalıştırma
`index.html` dosyasını tarayıcıda açın.

Demo giriş: herhangi bir bilgiyle giriş yapabilirsiniz.
